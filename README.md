# INFO 202 Final Project: Travel Scrapbook

**Natalie Crawford**

A faceted image collection of travel photos, with hand-labeled and classifier-predicted facet labels.

🔗 **Live site:** https://nataliecrawford.github.io/INFO202FinalProjectNatalieCrawford/

## Pages

| Page | Description |
|---|---|
| [Faceted Browser](https://nataliecrawford.github.io/INFO202FinalProjectNatalieCrawford/facetbrowser_nataliecrawford.html) | Browse and filter the full image collection by facet. Large file, so it may take a few seconds to load. |
| [Full Collection Labeled](https://nataliecrawford.github.io/INFO202FinalProjectNatalieCrawford/facetlabeling/LabelingFilesHtmls/full_info.html) | Every image with its caption and facet labels. |
| [Hand-Labeled Sample](https://nataliecrawford.github.io/INFO202FinalProjectNatalieCrawford/facetlabeling/LabelingFilesHtmls/hand_labeled.html) | The sample of images I labeled by hand. |
| [Classifier Predicted Labels](https://nataliecrawford.github.io/INFO202FinalProjectNatalieCrawford/facetlabeling/LabelingFilesHtmls/predicted_labels.html) | Facet labels predicted by the classifier for the rest of the collection. |

## Repository contents

| Path | What's in it |
|---|---|
| `index.html` | Home page for the site |
| `facetbrowser_nataliecrawford.html` | The faceted browser |
| `data/` | Source images (`images/`) and captions (`imagecaptions.tsv`) |
| `facetlabeling/` | Facet definitions (PDF), label CSVs, and the HTML label views |
| `classification/` | Classifier notebook (`.ipynb` plus a PDF export) and predicted labels for all data |
| `Hand_Classified_Sample.csv` | The hand-classified training sample |
